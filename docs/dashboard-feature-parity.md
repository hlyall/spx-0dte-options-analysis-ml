# Feature parity and limits

This is a portable companion refactor, not a claim that every private deployment feature or trained artifact has been reproduced. The pure analysis modules were retained and tested; the service, provider boundary and browser UI were rebuilt for a separate local application.

| Area | Portable release | What is required or excluded |
| --- | --- | --- |
| Regime / playbook engine | Retained numerical engine and session detection; descriptive IDs and independently written code-derived guides | Needs coherent option history and index context; missing feeds withhold outputs |
| Reversal attention | Red page theme at detected reversal, direction-aware position language, hidden-tab title flash in connected mode | Stale or unverified-session detection is held; no push service or broker exit |
| Last playbook | Current and last detected playbook through selected same-day cutoff | No later replay bars used |
| EMA retest setups | Retained bullish/bearish engine and history calculations; current states displayed | Complete usable minute history and verified cash session |
| Premium / implied movement | Retained fixed-call z-score and implied-price analysis | A current chain alone is not a historical premium series |
| Greek chain | Source bid/ask and Greeks with timestamps; clearly synthetic BSM demo | Licensed/entitled source for actual SPXW; Greek units remain explicit |
| Gamma / OI | Conditional call-positive/put-negative exposure by strike | Assumed inventory signs, partial observed chain, coherent time and known OI; no dealer-position claim |
| Sector graph | Retained rolling correlation engine and interactive SVG view of eleven sectors plus macro/news nodes | Descriptive correlation; daily/invalid bars do not become intraday data |
| Persistent sponge inference | Retained sector, macro, interaction and missing-input parsers/inference | Compatible validated model files supplied by user; no private artifacts or training pipeline bundled |
| Missing-input estimates | Compatible saved reconstruction-bundle support retained | No invented reconstructions when the required trained bundle is absent |
| News relevance | Preserved headline cue/routing semantics, visible multiple-sector/oil/rate routes | Twelve illustrative issuer rules; no full constituent database or paid newswire; routes are not causal weights |
| Playback | Manifest-driven normalized archive, date/minute playback and strict availability cutoff | Downloaded data only; no private recorder connection or bundled market history |
| Feed connections | Shared provider library, defaults and config with downloader | Vendor entitlements, limits and data terms still apply |
| Strategy view | Editable multi-leg expiration payoff, source chain and synthetic exploration | No account sizing, margin approval, recommended trade selection, or execution |
| Research tests | Core algorithm tests plus new integration, timing, units, calendar and isolation checks | Passing tests is not evidence of profitable trading |
| Private deployment | Excluded | Recorder jobs, broker/account integrations, Cloudflare/Next deployment glue, secrets, account histories, private model/data snapshots |

The original source hashes and portable export paths are in `dashboard-refactor-provenance.json`. These document provenance; they do not grant redistribution rights to third-party data or trained artifacts. Software is MIT under the root license; the manuscript has separate copyright terms.
